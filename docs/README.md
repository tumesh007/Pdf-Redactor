# PDF Redactor Documentation

## Overview

PDF Redactor is a cross-platform desktop application for permanently redacting visible personal identifiers from PDF files.

## Features

- ✅ Redact employee IDs
- ✅ Remove timestamps
- ✅ Hide footer text
- ✅ Custom redaction patterns
- ✅ Batch processing
- ✅ Preview before redaction
- ✅ Windows & Linux support

## Installation

### Windows
```batch
scripts\install.bat
```

### Linux
```bash
sudo bash scripts/install.sh
```

## Usage

1. Launch the application
2. Select PDF file(s) to redact
3. Choose redaction pattern or custom settings
4. Review preview
5. Click "Redact" to process
6. Save redacted PDF

## Configuration

Edit `config/settings.ini` to customize:
- Default redaction patterns
- Output quality
- Preview options
- Batch processing limits
